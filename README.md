# منصة الاختبارات الإلكترونية

منصة عربية لإجراء الاختبارات الإلكترونية مع مراقبة ومكافحة الغش ولوحة تحكم وتقارير.

- `index.html` — الصفحة الرئيسية (دخول الطالب / دخول المشرف)
- `student.html` — صفحة الطالب
- `admin.html` — لوحة المشرف والمعلمين

دليل التشغيل الكامل: [دليل-التشغيل.md](دليل-التشغيل.md)

> لا تضع أي أسرار (مثل توكن تيليجرام) في هذا المستودع — قيم `firebaseConfig` عامة بطبيعتها والحماية تتم عبر `firestore.rules`.
